Released API changes appear here. Product and website changes are on the [Heyrafiki changelog](https://heyrafiki.space/changelog).

<Update label="30 July 2026" description="Practitioner discovery" tags={["Added"]}>
**Added** sandbox Practitioner retrieval at `GET /v1/practitioners/{practitioner_id}`.

**Added** recurring weekly hours at `GET /v1/practitioners/{practitioner_id}/availability`.

**Added** synthetic Session list and retrieval without Person or clinical identifiers.

**Added** project-scoped Claim submission, information requests, evidence resubmission and line-level adjudication.

**Added** remittance allocation, ledger reconciliation and Claim settlement.

**Added** language-neutral conformance fixtures for the JavaScript SDK foundation.

**Added** tenant-scoped Booking list, retrieval and idempotent creation.

**Added** tenant-scoped Benefit eligibility and pre-authorization with one-Session reservations.

**Added** Webhook endpoint registration, Claim and remittance Events, signed delivery and endpoint controls.

**Added** thirteen read-only MCP tools with OAuth resource validation and project scopes.
</Update>

<Update label="29 July 2026" description="Private beta foundation" tags={["Added"]}>
**Added** authenticated API discovery at `GET /v1`.

**Added** synthetic Practitioner listings for sandbox projects at `GET /v1/practitioners`.

**Added** environment-scoped secret keys, stable error envelopes and per-key rate-limit headers.

**Published** the OpenAPI contract used by the generated endpoint reference.
</Update>
