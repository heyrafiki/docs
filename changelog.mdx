<Update label="15 July 2026" description="Platform preview and Docs foundation" tags={["Platform", "Documentation"]}>
  ## Platform canvas

  Platform routes now stay inside the browser viewport. Long surfaces scroll inside the product pane, so screenshots and modal states no longer create blank space below the application.

  ## Practitioner identity

  Practitioner Settings now include a title-before-name control and the shared avatar system. The current preview keeps these preferences local until the Profile service is connected.

  ## Developer Docs

  The repository-owned Docs now cover the Platform model, data ownership, operating principles, idempotency, Webhook reliability, Security and Privacy. Dark and light modes follow the reader's system preference.

  This entry covers frontend and documentation previews. It does not announce a production backend or public API.
</Update>
