## Register an endpoint

```bash
curl https://api.heyrafiki.space/v1/webhook_endpoints \
  -X POST \
  -H "Authorization: Bearer $HEYRAFIKI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://hooks.example.com/heyrafiki",
    "events": ["claim.submitted", "claim.settled", "remittance.reconciled"]
  }'
```

The response contains `signing_secret` once. Store it in a secret manager.

Private-beta endpoints use HTTPS on an approved public hostname. Redirects and private network addresses are refused.

## Verify a delivery

Heyrafiki sends:

- `Heyrafiki-Event-Id`: the stable event identifier;
- `Heyrafiki-Signature`: `t=<unix>,v1=<hex digest>`;
- `Content-Type: application/json`.

```json
{
  "id": "evt_01",
  "object": "event",
  "type": "sandbox.ping",
  "schema_version": "v1",
  "created_at": "2026-07-30T09:00:00.000Z",
  "livemode": false,
  "data": {
    "message": "pong"
  }
}
```

Compute HMAC-SHA256 over `<timestamp>.<raw body>` with the signing secret. Compare signatures in constant time and reject timestamps outside five minutes. Verify the raw bytes before parsing JSON.

## Test an endpoint

```bash
curl https://api.heyrafiki.space/v1/webhook_endpoints/whe_xxx/test \
  -X POST \
  -H "Authorization: Bearer $HEYRAFIKI_API_KEY"
```

The sandbox sends `sandbox.ping`. Transient failures use bounded retries and retain the same event identifier.

## Event types

| Event | Emitted when |
| --- | --- |
| `claim.submitted` | A Claim enters review |
| `claim.information_requested` | A payer requests evidence |
| `claim.resubmitted` | Requested evidence is supplied |
| `claim.approved` | The payer approves the full billed amount |
| `claim.partially_approved` | The payer approves part of the billed amount |
| `claim.denied` | The payer approves no amount |
| `claim.settled` | Cumulative remittance reaches the approved amount |
| `remittance.reconciled` | Every remittance allocation is recorded |

Claim Events contain public workflow identifiers and state. They do not contain Person, Member or clinical content.
