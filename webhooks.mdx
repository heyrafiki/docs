---
title: "Webhooks"
description: "Verify and process outbound Heyrafiki events."
---

Webhook delivery uses:

- a versioned event catalogue;
- a stable event identifier and schema version;
- signatures over the exact serialized body;
- replay-window verification;
- bounded retry for transient failures;
- an explicit endpoint authorization and egress policy before delivery.

Each released event has a documented schema, ordering behavior and verification example. Event access is scoped per project.
