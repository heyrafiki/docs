<Note>
  Beta. MCP access is available to approved Sandbox projects.
</Note>

Connect agents to Practitioner, Booking, Session, Benefits and Claims workflows through the same resource contracts as the REST API.

## Connect

Use this remote server URL in your MCP client:

```
https://mcp.heyrafiki.space/api/mcp
```

The client starts OAuth when authorization is required. Access tokens are bound to the MCP resource, a Heyrafiki Organization and approved scopes.

## Available tools

| Tool | Purpose | Required scope |
| --- | --- | --- |
| `list_practitioners` | List Practitioner profiles | `practitioners:read` |
| `get_practitioner` | Retrieve a Practitioner | `practitioners:read` |
| `get_practitioner_availability` | Read recurring weekly hours | `availability:read` |
| `list_bookings` | List Bookings | `bookings:read` |
| `get_booking` | Retrieve a Booking | `bookings:read` |
| `list_sessions` | List Sessions | `sessions:read` |
| `get_session` | Retrieve a Session | `sessions:read` |
| `list_claims` | List Organization-scoped Claims | `claims:read` |
| `get_claim` | Retrieve an Organization-scoped Claim | `claims:read` |
| `get_eligibility_check` | Retrieve an eligibility decision | `benefits:read` |
| `get_preauthorization` | Retrieve a pre-authorization | `benefits:read` |
| `list_remittances` | List project-scoped remittances | `remittances:read` |
| `get_remittance` | Retrieve a remittance | `remittances:read` |

## Access boundaries

Beta tools are read-only. Results are limited to the authenticated Sandbox project and Organization, and every call is checked against its required scope.

[Request access](https://heyrafiki.space/waitlist) for a Sandbox project.
