Heyrafiki connects People, Practitioners, Insurers and Organizations through shared Infrastructure for Care, Benefits and Payments.

These docs describe the architecture and engineering contracts that are ready for review today. The public API, SDKs, Webhooks and MCP tools will be documented when their authoritative specifications exist.

## Current stage

The repository contains broad frontend surfaces, seed data and typed service boundaries. It does not yet contain a deployed Convex or Postgres backend. Pages in these docs distinguish current behavior from planned integration work.
