---

The Heyrafiki API exposes Mental Healthcare infrastructure through versioned REST contracts. The sandbox includes Practitioner discovery, availability, Bookings, Sessions, Claim status and Webhooks.

It uses standard HTTP verbs, returns JSON, and authenticates with a secret key sent as a Bearer token.

```
https://api.heyrafiki.space/v1
```

<Note>
The API is in private beta. Sandbox keys are issued by invitation.
</Note>
