Discover a synthetic Practitioner, inspect recurring availability and read Session and Claim status.

## List Practitioners

```bash
curl "https://api.heyrafiki.space/v1/practitioners?limit=2" \
  -H "Authorization: Bearer sk_test_xxxxxxxxxxxxxxxx"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "prc_2481",
      "object": "practitioner",
      "name": "Emily Makena",
      "profession": "Clinical Psychologist",
      "location": {
        "city": "Nairobi",
        "country": "Kenya"
      },
      "session_fee": {
        "amount": 350000,
        "currency": "KES"
      }
    }
  ],
  "has_more": false
}
```

`limit` accepts an integer from `1` to `100` and defaults to `20`.

## Retrieve a Practitioner

```bash
curl "https://api.heyrafiki.space/v1/practitioners/prc_2481" \
  -H "Authorization: Bearer sk_test_xxxxxxxxxxxxxxxx"
```

The response uses the same Practitioner object returned by the list operation.

## Retrieve recurring availability

```bash
curl "https://api.heyrafiki.space/v1/practitioners/prc_2481/availability" \
  -H "Authorization: Bearer sk_test_xxxxxxxxxxxxxxxx"
```

```json
{
  "object": "availability",
  "practitioner_id": "prc_2481",
  "timezone": "Africa/Nairobi",
  "weekly_hours": [
    {
      "weekday": 1,
      "start": "09:00",
      "end": "17:00",
      "formats": ["online", "in_person"]
    }
  ]
}
```

`weekday` uses `0` for Sunday through `6` for Saturday. Hours are local to the returned IANA timezone. These are recurring weekly hours, not a promise that a particular Session slot remains bookable.

## List Sessions

```bash
curl "https://api.heyrafiki.space/v1/sessions?limit=10" \
  -H "Authorization: Bearer sk_test_xxxxxxxxxxxxxxxx"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "ses_demo_jubilee_001",
      "object": "session",
      "practitioner_id": "prc_2481",
      "starts_at": "2026-08-02T07:00:00.000Z",
      "ends_at": "2026-08-02T08:00:00.000Z",
      "timezone": "Africa/Nairobi",
      "format": "online",
      "status": "confirmed",
      "payment_source": "covered"
    }
  ],
  "has_more": false
}
```

Session responses intentionally omit Person, clinical, coverage and payment-provider identifiers.

## List Claims

```bash
curl "https://api.heyrafiki.space/v1/claims?limit=10" \
  -H "Authorization: Bearer sk_test_xxxxxxxxxxxxxxxx"
```

```json
{
  "object": "list",
  "data": [
    {
      "id": "clm_demo_jubilee_001",
      "object": "claim",
      "status": "submitted",
      "amount": {
        "currency": "KES",
        "billed": 380000,
        "approved": null,
        "settled": null
      },
      "service_period": {
        "starts_at": "2026-07-20T05:00:00.000Z",
        "ends_at": "2026-07-20T05:50:00.000Z"
      }
    }
  ],
  "has_more": false
}
```

Claim responses are tenant-scoped and omit Person, payer and clinical-record identifiers.

## Conventions

- IDs are opaque strings. Never parse them.
- Amounts are integers in the currency's minor unit. `350000` is KES 3,500.00.
- Currency codes use ISO 4217.
- Unknown fields may be added. Ignore fields your integration does not use.

The generated endpoint reference is built from the versioned OpenAPI contract in this repository.
