---
title: "Preview the frontend locally"
description: "Run the current Heyrafiki frontend and inspect each product surface."
---

This tutorial runs the frontend with its local seed data. It does not connect a production account or create clinical or financial records.

## Prerequisites

- Repository access
- Node.js 20.17 or a newer supported LTS release
- npm

## Run the app

From the repository root:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Inspect the product surfaces

Use these routes to review the current frontend:

| Surface | Route |
| --- | --- |
| People | `/app` |
| Practitioners | `/practice` |
| Organizations | `/org` |
| Insurers | `/insurer` |
| Developers | `/dev` |

The account menu in the top bar links the available preview workspaces. Seeded actions demonstrate interaction contracts, but they do not move money, submit Claims or write production records.

## Verify a change

Run the repository checks before requesting review:

```bash
npm run lint
npm run build
```

Verify visible changes in a real browser at desktop and mobile widths. Check keyboard access, focus visibility, empty states, loading states and overflow.
