Heyrafiki is an Infrastructure layer for Mental Healthcare. Therapy discovery, Practice tools, Sessions, Claims, Benefits and Payments are connected parts of that system.

## Product surfaces

| Surface | Primary responsibility |
| --- | --- |
| People | Find and fund Care, manage Sessions and control sharing |
| Practitioners | Run a Practice, communicate with Clients and manage revenue |
| Organizations | Fund Programs and review aggregate participation |
| Insurers | Operate Claims and Practitioner Networks |
| Developers | Integrate through versioned APIs, Webhooks and tools |

## Human-First intelligence

Iris supports Matchmaking, scheduling, Scribe drafts and product guidance. Clinical Notes remain drafts until a Practitioner approves them. People can inspect and remove non-clinical memory facts when that backend capability ships.

## Integration boundary

Components do not call external vendors directly. Typed services own Payments, identity, video, messaging, storage and model access. A provider can change without rewriting the product surface that uses it.

## Current implementation

The frontend uses seed data shaped like the planned service contracts. Backend integrations must replace data sources without changing established workflows unless evidence supports a product change.
